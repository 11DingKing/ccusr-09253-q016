# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 活动时间修订

活动组织方可整体更正一场实训（activity）的起止时间，而无需逐个重写学员签到：

- 修订以独立的有效版本叠加在重放内核上，**原始签到事件永不修改**；重放结果同时保留 `raw_seconds` 与 `effective_seconds`。
- 每个修订带单调版本号与 `draft → approved → revoked` 生命周期；批准/撤销都会向只追加事件流写入一条生命周期事件。
- `student_ids` 省略表示适用全体学生；给出名单即为部分学生例外（在同一活动上优先于全体修订）。已撤销修订回退到更早的有效版本。
- 影响预览给出受影响学生、确认/待定时长变化、**按学术日（培养方案时区）的日归属变化**以及**修订窗与原始签到窗的重叠区间**；支持已存草稿预览与不落库的内联预览。
- 冻结快照依据事件流的单调序号 cutoff 重放：已冻结快照永远使用当时的修订版本，新冻结采用最新已批准（未撤销）修订；快照内 `applied_revisions` 记录所用版本清单。

接口（均位于 `/api/plans/{plan_version}` 下）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/revisions` | 草拟修订（自动分配版本号） |
| POST | `/revisions/preview` | 内联时间窗的影响预览（不落库） |
| GET | `/revisions` | 版本查询，可按 `activity_id`、`status_filter` 过滤 |
| GET | `/revisions/{revision_id}` | 单个修订详情 |
| POST | `/revisions/{revision_id}/preview` | 已存草稿/修订的影响预览 |
| POST | `/revisions/{revision_id}/approve` | 审批（条件更新，并发安全） |
| POST | `/revisions/{revision_id}/revoke` | 撤销已批准修订 |

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。
